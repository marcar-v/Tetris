# Puzzle / Tetris-like — Unity

## Descripción
Juego de puzzle tipo Tetris desarrollado en Unity. Proyecto enfocado en la lógica de piezas, control del ritmo de juego y gestión de estados.

## Características principales
- Sistema completo de tetrominos.
- Movimiento y rotación de piezas.
- Incremento progresivo de la velocidad.
- Sistema de puntuación.
- Menú principal, pausa y *Game Over*.
- Música y efectos de sonido.
- Soporte para PC y versión Android (rama independiente).

## Tecnologías
- Unity
- C#
- UI Canvas
- Control de estados de juego

## Estado del proyecto
Versión final para PC completada. Proyecto cerrado para portfolio.
